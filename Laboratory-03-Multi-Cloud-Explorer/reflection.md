# Mission 3 Reflection

This laboratory activity helped me realize that choosing a cloud provider is not just about picking the most popular platform. Each provider offers different services, features, and strengths that can be matched to the specific needs of a business or organization.

The cloud platform that impressed me the most was Google Cloud Platform (GCP). I was particularly interested in its capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. These features make GCP a good choice for organizations that work with advanced technologies and large amounts of data.

AWS, Azure, and GCP are similar in many ways. All three offer virtual machines, object storage, databases, networking, identity and access management, and other services needed to develop and run cloud applications. They also provide global infrastructure, management consoles, scalability, and security features. These capabilities allow organizations to use cloud resources without having to manage all of their physical hardware.

Business requirements are very important when selecting a cloud provider. Factors such as budget, existing technology, performance, scalability, security, location, and application requirements should be considered before making a decision. For example, Azure may be more suitable for an organization that already uses Microsoft technologies, while GCP can be a good option for organizations focused on Artificial Intelligence, Machine Learning, or Kubernetes.

Working as a Cloud Solutions Consultant taught me to focus on the client's actual needs rather than simply looking at individual cloud services. I learned that an effective cloud recommendation should connect technical features with the organization's goals and requirements.

My GitHub Cloud Computing Portfolio has also improved after completing this mission. It now includes organized research, cloud comparisons, client recommendations, decision matrices, Linux investigation results, screenshots, and reflections. This makes my portfolio more organized and provides a useful record of what I have learned and practiced in Cloud Computing throughout the semester.
